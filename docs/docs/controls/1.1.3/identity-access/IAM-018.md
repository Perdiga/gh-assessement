# IAM-018: Enterprise-to-org access is documented

**Catalog version:** 1.1.3  
**Domain:** Identity & Access  
**Severity:** medium  
**Maturity stage:** Mature  
**Well-Architected mapping:** Observability, Simplicity

## Objective

Establish and verify the organizational practice: enterprise-to-org access is documented.

## Requirement

Enterprise-to-org access is documented.

## Risk

Meaningful control weakness requiring planned remediation.

## Evidence sources

- **Source:** `Enterprise membership / SSO`
  - **Fields:** `enterprise_membership`
  - **Evidence key:** `identity.enterprise_access`

## Evaluation logic

**Mode:** `manual_or_hybrid`

Evaluate collected evidence for `enterprise_membership` against the stated requirement; distinguish missing evidence from a failing control.

## Expected result

PASS when the requirement is demonstrably satisfied; PARTIAL when implementation is incomplete; FAIL when materially absent; NOT ASSESSED when evidence is unavailable; N/A only with documented rationale.

## Exception criteria

A documented, approved exception with owner, rationale, compensating control and expiry.

## Remediation guidance

Remediate the identified gap for: Enterprise-to-org access is documented. Assign an accountable owner and target date.

## Maturity-stage basis

Organizationally established, standardized or governed practice aligned to the GitHub Well-Architected Mature stage.
