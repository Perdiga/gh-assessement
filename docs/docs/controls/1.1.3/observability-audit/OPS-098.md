# OPS-098: CI/CD reliability metrics are tracked

Establish and verify the organizational practice: ci/cd reliability metrics are tracked.

Remediate the identified gap for: CI/CD reliability metrics are tracked. Assign an accountable owner and target date.

Advanced, automated, optimized, continuously measured or resilient practice aligned to the GitHub Well-Architected Advance stage.
