# CI-061: Production deployments require protected environments

**Catalog version:** 1.1.3  
**Domain:** CI/CD & GitHub Actions  
**Severity:** critical  
**Maturity stage:** Mature  
**Well-Architected mapping:** Scalability, Resiliency, Efficiency, Disaster Recovery, Modularity, Interoperability, Simplicity, Observability

## Objective

Establish and verify the organizational practice: production deployments require protected environments.

## Requirement

Production deployments require protected environments.

## Risk

Material security, availability or compliance exposure.

## Evidence sources

- **Source:** `GET /repos/&#123;owner&#125;/&#123;repo&#125;/environments`
  - **Fields:** `protection_rules`
  - **Evidence key:** `ci.environments`

## Evaluation logic

**Mode:** `automated`

Evaluate collected evidence for `protection_rules` against the stated requirement; distinguish missing evidence from a failing control.

## Expected result

PASS when the requirement is demonstrably satisfied; PARTIAL when implementation is incomplete; FAIL when materially absent; NOT ASSESSED when evidence is unavailable; N/A only with documented rationale.

## Exception criteria

A documented, approved exception with owner, rationale, compensating control and expiry.

## Remediation guidance

Remediate the identified gap for: Production deployments require protected environments. Assign an accountable owner and target date.

## Maturity-stage basis

Organizationally established, standardized or governed practice aligned to the GitHub Well-Architected Mature stage.
