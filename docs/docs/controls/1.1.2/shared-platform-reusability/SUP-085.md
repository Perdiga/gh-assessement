# SUP-085: Reusable components are discoverable

**Catalog version:** 1.1.2  
**Domain:** Shared Platform & Reusability  
**Severity:** medium  
**Maturity stage:** Start  
**Well-Architected mapping:** Scalability, Resiliency, Efficiency, Disaster Recovery, Modularity, Interoperability, Simplicity, Observability

## Objective

Establish and verify the organizational practice: reusable components are discoverable.

## Requirement

Reusable components are discoverable.

## Risk

Meaningful control weakness requiring planned remediation.

## Evidence sources

- **Source:** `Organization/repository inventory`
  - **Fields:** `catalog,README`
  - **Evidence key:** `sup.discoverability`

## Evaluation logic

**Mode:** `manual_or_hybrid`

Evaluate collected evidence for `catalog,README` against the stated requirement; distinguish missing evidence from a failing control.

PASS when the requirement is demonstrably satisfied; PARTIAL when implementation is incomplete; FAIL when materially absent; NOT ASSESSED when evidence is unavailable; N/A only with documented rationale.

## Remediation guidance

Remediate the identified gap for: Reusable components are discoverable. Assign an accountable owner and target date.

## Maturity-stage basis

Foundational practice aligned to the GitHub Well-Architected Start stage.
