# ORG-002: Repository creation visibility is controlled

**Catalog version:** 1.1.2  
**Domain:** Organization Governance  
**Severity:** high  
**Maturity stage:** Start  
**Well-Architected mapping:** Observability, Simplicity

## Objective

Establish and verify the organizational practice: repository creation visibility is controlled.

## Requirement

Repository creation visibility is controlled.

## Risk

Significant governance, security or operational exposure.

## Evidence sources

- **Source:** `GET /orgs/&#123;org&#125;`
  - **Fields:** `members_can_create_public_repositories, members_can_create_private_repositories`
  - **Evidence key:** `org_settings.repo_creation_policy`

## Evaluation logic

**Mode:** `automated`

Evaluate collected evidence for `members_can_create_public_repositories, members_can_create_private_repositories` against the stated requirement; distinguish missing evidence from a failing control.
